# Auditorías CBC · Canal Tradicional — Mockup

Mockup navegable de la plataforma de control de auditorías para CBC Perú, operada por TT Audit.

- `index.html` — Dashboard de control (CBC / supervisión)
- `visita.html` — Detalle de visita PDV (indicadores, fotos, GPS)
- `app.html` — App móvil del auditor

Sitio estático, sin build. Los datos son ilustrativos.
